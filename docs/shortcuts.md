# Keyboard shortcuts

The defaults. Every shortcut can be rebound in Settings → Keybinds or in the `[keybinds]` table of `jelly.toml` (see [config.md](config.md)).

| Action | Keys |
|---|---|
| New tab | ⌘T |
| Close pane (the tab when it's the last) | ⌘W |
| Close tab | ⌘⌥W |
| Split right | ⌘D |
| Split down | ⌘⇧D |
| Focus pane above / below | ⌘⌥↑ / ⌘⌥↓ |
| Zoom pane | ⌘⇧↩ |
| Equalize panes | ⌘⌃= |
| Next / previous tab | ⌘⌥→ / ⌘⌥←, or ⌘⇧] / ⌘⇧[ |
| Move tab left / right | ⌘⇧← / ⌘⇧→ |
| Tab 1–9 | ⌘1 … ⌘9 |
| New session | ⌘⇧N |
| Next / previous session | ⌃⇥ / ⌃⇧⇥, or ⌘⌃] / ⌘⌃[ |
| Session 1–9 | ⌘⌃1 … ⌘⌃9 |
| Toggle sidebar | ⌘0 |
| Toggle explorer | ⌘E |
| Preview Markdown (selected file, or the directory's README) | ⌘⇧M |
| Command palette | ⌘K |
| Jump to waiting agent | ⌘⇧A |
| Find | ⌘F |
| Clear | ⌘⇧K |
| Reload config | ⌘⇧, |
| Settings | ⌘, |
| Quick terminal (from any app) | ⌃Space |
